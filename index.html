One-time setup

Add your free Pl@ntNet key

  1. Create a free account at my.plantnet.org
  2. Open your API key settings and tick "expose my API key".
  3. Under "Authorized domains", add https://texnonik.github.io and save.
  4. Copy the key and paste it below.

The free plan allows 500 scans a day. The key stays on this phone and is sent only to Pl@ntNet, which uses your photos for identification.
