Настройка один раз

Добавьте бесплатный ключ Pl@ntNet

  1. Создайте бесплатный аккаунт на сайте my.plantnet.org
  2. Откройте настройки ключа API и поставьте галочку «expose my API key».
  3. В разделе «Authorized domains» добавьте https://texnonik.github.io и сохраните.
  4. Скопируйте ключ и вставьте его ниже.

Бесплатный тариф позволяет делать 500 определений в день. Ключ хранится на этом телефоне и отправляется только в Pl@ntNet, который использует ваши фото для определения растений.
